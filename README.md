\# PPE Detection



Système de détection des équipements de protection individuelle basé sur YOLOv8, avec un module de reconnaissance faciale utilisant DeepFace.



\## Fonctionnalités



\- Détection des EPI en temps réel

\- Détection du casque, du gilet, des lunettes et des gants

\- Reconnaissance faciale

\- Utilisation d'une webcam

\- Modèle YOLOv8 personnalisé



\## Exécution



```bash

conda activate facesense

python test\_ppe\_camera.py
